BALUSTRADE MODULAR SYSTEM LITE
==============================

This free LITE version includes the complete modular balustrade editor tool plus a
subset of the content: 2 pillar styles (V1 + V2), 3 of the 12 baluster styles,
1 pillar top, and one finish in New and Worn condition - for all render pipelines.

The package contains dedicated materials for Built-In, URP and HDRP (see the
folders below). After import, the included editor tool automatically assigns
the materials matching your project's render pipeline - no manual setup needed.
You can simply import everything; deselecting the folders of the other
pipelines (see "Optional" below) just keeps your project smaller.

Demo scenes (one per pipeline):
- HDRP:     Balustrade Modular System/HDRP/Scenes/DemoScene.unity
- URP:      Balustrade Modular System/URP & Built-In/URP/Scene/DemoScene.unity
- Built-In: Balustrade Modular System/URP & Built-In/Built-In/Scenes/DemoScene.unity
Please open the demo scene matching your active render pipeline.

Full documentation:
See "Balustrade Modular System LITE - Documentation.rtf" in this folder for the
complete user guide (setup, all tool features, script reference, troubleshooting).


Quick Start (any render pipeline):
Import the complete package, then open "Tools/Balustrade Modular System".
The materials for your active render pipeline are assigned automatically. Done.

Optional - keep your project smaller:
During import you can deselect the folders of the pipelines you don't use:
- Built-In project: deselect the "URP" and "HDRP" folders
- URP project:      deselect the "Built-In" and "HDRP" folders
- HDRP project:     deselect the "URP & Built-In" folder
